# Exercício Prático: A Minha Cidade 🏙️

Hoje preparámos as máquinas e criámos a primeira página do nosso portefólio. Agora é a vossa vez de fazer o mesmo, sozinhos, com uma página sobre **a vossa cidade**.

O vosso objetivo é confirmar que têm todas as ferramentas a funcionar e criar a vossa primeira página web.

### Missão 1: O Ambiente Está Pronto?

1. Abram um terminal novo no VS Code (**Ctrl \+ \`**).  
2. Escrevam, um de cada vez:  
   - `node -v`  
   - `npm -v`  
   - `git --version`  
3. Tirem uma captura de ecrã do terminal com as três respostas (**Windows:** **Windows \+ Shift \+ S**; **Mac:** **Cmd \+ Shift \+ 4**).  
4. Abram as Extensões do VS Code (**Ctrl \+ Shift \+ X**) e confirmem que têm o **Live Server** e o **Prettier** instalados.

### Missão 2: Arrumar a Casa

1. Dentro de `Documentos/dawfs`, criem a pasta `exercicios-uf1.1`.  
2. Dentro dela, criem a pasta `sessao-01`.  
3. Abram a pasta `exercicios-uf1.1` no VS Code (**File** → **Open Folder...**).

A vossa pasta `dawfs` deve ficar assim:

```
dawfs/
├── exercicios-uf1.1/
│   └── sessao-01/
└── portefolio/
    └── index.html
```

*Lembrem-se da Regra de Ouro: nomes sem espaços, sem acentos e em minúsculas.*

### Missão 3: A Minha Cidade

1. Dentro de `sessao-01`, criem o ficheiro `cidade.html`.  
2. Escrevam um título principal (`<h1>`) com o nome da vossa cidade (ou da terra onde nasceram).  
3. Escrevam **três parágrafos** (`<p>`):  
   - onde fica;  
   - uma coisa pela qual é conhecida;  
   - o que mostrariam a quem a visitasse.  
4. Guardem e abram a página com o **Live Server** (botão direito → **Open with Live Server**).  
5. Ponham o browser e o VS Code lado a lado, mudem o texto de um parágrafo, guardem e confirmem que a página atualiza sozinha.

*Exemplo esperado no browser: o nome da cidade em letras grandes e, por baixo, os três parágrafos.*

### Missão 4: O Relatório

Entreguem as respostas:

1. As versões instaladas: Que versões vos apareceram para `node -v`, `npm -v` e `git --version`? Resposta: \[Preencher\]

2. O endereço: Qual é o endereço completo que aparece no browser quando abrem o `cidade.html` com o Live Server? Resposta: \[Preencher\]

3. A diferença: Qual é a diferença entre abrir a página com duplo clique e abri-la com o Live Server? Resposta: \[Preencher\]

### 🚀 Desafio Bónus (Para os mais rápidos)

1. Abram as DevTools (**F12**) na vossa página e mudem o nome da cidade no título. Depois atualizem a página (**F5**). O que aconteceu e porquê?  
2. Abram o código-fonte (**Ctrl \+ U**) de um site de que gostem e procurem (**Ctrl \+ F**) uma tag `<h1>` ou `<p>`. Encontraram?
