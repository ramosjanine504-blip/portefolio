2. O ciclo de trabalho

git add: Serve para selecionar os ficheiros que queremos guardar.

git commit: Serve para guardar as alterações no nosso computador, com uma mensagem.

git push: Serve para enviar as alterações para o GitHub.

São três passos separados porque primeiro selecionamos os ficheiros, depois guardamos as alterações e, por último, enviamos o trabalho para o GitHub.
