Missão 3: O Relatório – CSS

1. As Três Formas de Inclusão de CSS

Existem três formas de aplicar CSS ao HTML:

Inline: o CSS é escrito diretamente dentro da tag HTML, usando o atributo style.

Interno: o CSS é escrito dentro da tag <style>, no próprio documento HTML.

Externo: o CSS é escrito num ficheiro separado, com extensão .css, ligado ao HTML.

O CSS externo é considerado a melhor prática porque permite organizar melhor o código, reutilizar os mesmos estilos em várias páginas e facilitar a manutenção do site.

2. Seletores de Tipo vs Classe vs ID

Seletor de tipo (p): aplica estilos a todos os parágrafos. Exemplo: mudar a cor de todos os textos dos parágrafos.

Seletor de classe (.destaque): aplica estilos aos elementos que têm essa classe. Exemplo: destacar uma frase importante.

Seletor de ID (#formulario): aplica estilos a um elemento específico com esse identificador. Exemplo: definir o estilo de um formulário.

3. Seletores Descendentes

A regra nav, a { ... }, com vírgula, aplica o mesmo estilo a todos os elementos nav e a todos os links a.

A regra nav a { ... }, com espaço, aplica o estilo apenas aos links que estão dentro de um elemento nav.

4. Depuração com DevTools

O separador "Styles" das DevTools permite ver os estilos aplicados a um elemento HTML. Também ajuda a identificar erros, mostrando regras que foram ignoradas ou substituídas por outras. Assim, o programador pode testar alterações e descobrir por que razão um estilo não está a funcionar.
