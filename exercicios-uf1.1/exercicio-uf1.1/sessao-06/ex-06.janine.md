MISSÃO 3 – O RELATÓRIO

1. A diferença entre name e id

O atributo id serve para identificar um campo de forma única dentro da página HTML. O atributo name serve para identificar o campo quando os dados do formulário são enviados.

Quando um campo não tem o atributo name, o seu valor normalmente não é enviado junto com os dados do formulário.

2. Rótulos e acessibilidade

O placeholder apresenta uma indicação dentro do campo, mas desaparece quando começamos a escrever. A etiqueta <label> identifica o campo e ajuda as pessoas a compreenderem o que devem preencher.

Quando clicamos no texto de uma <label> corretamente configurada, o navegador coloca automaticamente o cursor no campo correspondente ou seleciona a opção.

3. Rádios vs Checkboxes

Os botões de rádio (type="radio") são utilizados quando queremos escolher apenas uma opção entre várias.

As caixas de verificação (type="checkbox") são utilizadas quando podemos escolher uma ou várias opções ao mesmo tempo.

A regra técnica é que os botões de rádio que pertencem ao mesmo grupo devem ter o mesmo atributo name.
