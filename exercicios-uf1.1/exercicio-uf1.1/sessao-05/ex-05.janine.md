MISSÃO 3 – O RELATÓRIO

1. Segurança e navegação

O atributo target="_blank" serve para abrir um link num novo separador do navegador.

O atributo rel="noreferrer noopener" é importante para proteger a nossa página, evitando que a página aberta tenha acesso à página original e impedindo também o envio de informações de referência.

2. Escolha de listas

A lista <ul> é utilizada quando os elementos não precisam de uma ordem específica. Por exemplo, uma lista de ingredientes de uma receita.

A lista <ol> é utilizada quando os elementos precisam de seguir uma ordem. Por exemplo, os passos para preparar uma receita.

3. Tabelas e semântica

Não devemos utilizar o elemento <table> para organizar visualmente uma página porque as tabelas servem para apresentar dados organizados em linhas e colunas, e não para criar o layout de um site.

O único objetivo legítimo de uma tabela é apresentar informações relacionadas em linhas e colunas, como horários, preços ou resultados de notas.
