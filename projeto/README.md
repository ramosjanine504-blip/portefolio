# 💼 Projeto Contínuo — O Meu Portefólio

O projeto desta UF é o vosso **portefólio pessoal**: o site onde se apresentam a futuros empregadores, com quem são, o vosso percurso, os vossos projetos e como vos contactar.

Construímos o portefólio **em demonstração ao vivo**: o formador escreve o código do portefólio da **Ana Martins**, uma futura programadora inventada, e vocês escrevem a mesma estrutura no vosso computador, **com os vossos dados**. Em cada aula o site cresce um bocadinho, sempre e só com o que acabámos de aprender. No fim da UF, cada um tem o seu portefólio completo e publicado na internet.

## 📂 Como usar esta pasta

Cada subpasta `sessao-NN/` é uma **fotografia do portefólio da Ana no fim dessa aula**.

- **Estiveram na aula?** Não precisam desta pasta: o vosso projeto é o que construíram no vosso computador. Podem usá-la para comparar e encontrar diferenças.
- **Faltaram a uma aula?** Leiam o guia dessa aula (em `classes/`) e façam os passos no vosso portefólio. Se ficarem perdidos, comparem com a pasta `sessao-NN/` dessa aula.
- **Algo correu mal e o projeto deixou de funcionar?** Comparem o vosso ficheiro com o da aula correspondente.

> A partir da aula 3 o portefólio também vive no GitHub de cada formando e cada aula termina com um *commit*.

## 🗺️ Roteiro na UF1.1

O roteiro segue o plano da UF. Pode mudar ao longo das aulas, conforme o ritmo da turma.

1. **Aula 01** ✅ ([`sessao-01/`](./sessao-01/)): criar a pasta `portefolio/` e o primeiro `index.html` (o nome e uma frase); abrir com o Live Server.
2. **Aula 02** ✅ ([`sessao-02/`](./sessao-02/)): estrutura completa (doctype, head, body); secções "Sobre mim", "O meu percurso" e "Contactos" com títulos, parágrafos, ênfase, comentários e entidades.
3. **Aula 03** ✅ ([`sessao-03/`](./sessao-03/)): o portefólio passa a ser um repositório Git, publicado no GitHub; fotografia com `<img>`, abreviatura, `span` com `lang` e um testemunho com `blockquote` e `div`.
4. **Aula 04** ⏳: organizar a página com `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
5. **Aula 05** ⏳: novas páginas `projetos.html` e `contactos.html`; menu de navegação entre as páginas; links para o e-mail e para o GitHub; listas de competências; uma tabela com o percurso (anos, formação ou emprego, local).
6. **Aula 06** ⏳: formulário de contacto em `contactos.html` (nome, e-mail, assunto, mensagem).
7. **Aula 07** ⏳: validação HTML5 no formulário; `<meta>` description, viewport e favicon em todas as páginas.
8. **Aula 08** ⏳: criar `css/style.css` e ligá-lo a todas as páginas; primeiras regras com seletores de tipo, classe e id.
9. **Aula 09** ⏳: identidade visual (fontes, cores, unidades); cartões de projeto e do testemunho com o box model.
10. **Aula 10** ⏳: cabeçalho e menu com Flexbox; grelha de projetos com Grid (com `flex-wrap`/`auto-fit` para se adaptar à largura do ecrã).
11. **Aula 11** ⏳: imagens dos projetos com `figure`/`figcaption`, um vídeo curto de apresentação; efeitos `:hover`/`:focus` e transições.
12. **Aula 12**: pausa no projeto (avaliação individual).
13. **Aula 13** ⏳: media queries mobile-first (menu e grelha adaptam-se ao telemóvel); planeamento do projeto final em grupo.
14. **Aula 14** ⏳: ramo (branch) `experiencia-bootstrap`: reconstruir a página de projetos com Bootstrap e comparar com o CSS feito à mão.
15. **Aula 15** ⏳: componentes reutilizáveis (botão, cartão) com variáveis CSS; acessibilidade: contraste, teclado, skip link, ARIA.
16. **Aula 16** ⏳: auditoria com o W3C Validator e o Lighthouse; otimizar imagens, `loading="lazy"`, minificação.
17. **Aula 17** ⏳: `README.md` do portefólio e comentários no código; publicação no GitHub Pages.
18. **Aula 18** ⏳: revisão final do portefólio (versão 1.0).
19. **Aula 19**: projeto final em grupo (um site institucional novo); o portefólio serve de referência.
